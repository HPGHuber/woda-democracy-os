# Security policy

This repository is not a production election system. Do not test against public election infrastructure or third-party systems without written authorization.

Never submit personal data, voter-register extracts, real ballots, credentials or private keys. Report suspected vulnerabilities privately to repository maintainers. Establish a dedicated security contact and coordinated disclosure process before any pilot involving personal data.

A production election deployment is out of scope until lawful authorization, independent audits, public-verifiability design, coercion analysis, accessibility review, incident response and a competent election authority are in place.
